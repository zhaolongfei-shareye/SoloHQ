# SoloHQ 发布与推广文案

## 一句话定位

Local-first dashboard for one-person companies. 一人公司的本地优先仪表盘。

## Product Hunt

Title: SoloHQ - Local-first dashboard for one-person companies

Tagline: Projects, memos, bookmarks, search, and revenue in one local-first dashboard. No backend, no account, no lock-in.

First comment: I built SoloHQ because one-person companies still need a command center: projects, memos, bookmarks, and revenue in one screen. Everything is stored in the browser and can be exported as JSON, so your data always belongs to you. Feedback welcome.

## Hacker News (Show HN)

Title: Show HN: SoloHQ - Local-first dashboard for one-person companies

Body: I built a local-first dashboard for solo founders. It combines a project board, workspace memos, quick search, bookmark collections, and revenue tracking in a single React app. No backend, no accounts, no data collection; everything is stored in localStorage and can be exported as JSON. Live demo: https://www.agentsbin.com/solohq/demo/

## Reddit (r/SideProject)

Title: I built SoloHQ, a local-first dashboard for solo founders

Body: SoloHQ is a dashboard for one-person companies: track projects and milestones, keep per-project memos, search the web, organize bookmarks, and track MRR. It is a static React app with no backend; all data lives in localStorage and can be exported/imported as JSON. The whole project is open source under MIT.
