# Contributing

Thanks for your interest in SoloHQ.

## Development setup

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev` and open http://localhost:5173/.

## Before submitting a pull request

- Run `npm run lint`
- Run `npm test`
- Run `npm run build`

## Commit messages

Use conventional commit style: `feat:`, `fix:`, `docs:`, `test:`, `chore:`, and so on.

## Pull requests

Describe the change, link any related issue, and include a screenshot when the UI changes.
