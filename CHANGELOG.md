# Changelog

## [Unreleased]

## [0.2.5] - 2026-08-26

### Added

- Date-stamped workspace notes with automatic daily grouping
- A date index for jumping directly to notes from any day
- Pinned-note summaries that stay at the top and jump back to the source note

### Fixed

- Aligned the workspace drag handle with the note-panel header

## [0.2.4] - 2026-08-26

### Fixed

- Use the active SoloHQ theme for the Google quick-app settings panel, preventing a white panel in Midnight Dark mode.

### Added

- Delete projects from the edit panel with a confirmation dialog
- Abandoned counter that increments only for projects with real notes
- Demo session reset and top notice on agentsbin.com
- Homepage SoloHQ card and unified about footer on agentsbin.com

## [0.1.0] - 2026-08-15

### Added

- Project board with developing, launched, revenue, and abandoned milestones
- Per-project workspace memos
- Multi-engine quick search
- Bookmark collections
- Google app shortcuts
- Four dashboard themes
- Drag-to-reorder widgets
- JSON backup export and import
- LocalStorage persistence
- CI workflow, tests, and open-source documentation
