# Code of Conduct

SoloHQ aims to be an open, welcoming project for contributors of all backgrounds.

## Expectations

- Be respectful and constructive.
- Focus feedback on code and ideas, not people.
- Assume good faith.
- Keep discussions inclusive and harassment-free.

## Reporting

If you experience or witness unacceptable behavior, please report it privately through a GitHub Security Advisory at https://github.com/zhaolongfei-shareye/SoloHQ/security/advisories/new.
